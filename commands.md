# Five essential Git commands
1. `git clone`: downloads a project from a remote server to your local machine.
2. `git add`: stages edited files to prepare them for your next commit.
3. `git commit`: saves your staged changes permenanetly as a local snapshot with a message. 
4. `git push`: uploads your local updates to the shared remote repository.
5. `git pull`: downloads and merges the team's latest changes into your local files.
